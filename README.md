# FYP2024
This is my Final Year Project at the Hong Kong Polytechnic University. It was made in Google Colab with PyTorch.

## Objective:
To use the ECAPA-TDNN Deep Learning architecture and train it for Sound Event Detection. The dataset used is the Urban8kSound dataset, consisting of 8,732 sounds in 10 different classes.

## Content:
The content here is showing the 10-Cross Validation code using ECAPA-TDNN
